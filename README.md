

# PCA-Based Breast Cancer Gene Expression Analysis

## Project Description
This project applies Principal Component Analysis (PCA) to breast cancer gene-expression data in order to explore patterns between ER-positive and ER-negative tumor samples.

The notebook demonstrates:
- Data preprocessing and integration
- Covariance-based dimensionality reduction
- Eigenvalue and eigenvector computation
- Visualization of principal component directions
- Projection of biological samples into lower-dimensional space

---

## Objectives
The primary objectives of this project are:

1. Understand how PCA reduces high-dimensional biological data.
2. Explore separability between ER classes.
3. Visualize dominant variance directions.
4. Interpret biological clustering patterns using statistical methods.

## Workflow Summary
### Data Preparation
Gene-expression matrices and class labels are loaded and aligned.

### PCA Implementation
The notebook manually computes:
- Mean-centered data
- Covariance matrix
- Eigenvalues
- Eigenvectors
- Principal component projections

### Visualization
Multiple plots are generated to interpret:
- Raw gene-expression relationships
- Principal component orientations
- Sample distributions along PC axes
